03 / THE MODEL

ISLTransformer — attention over time, honesty over metrics.

A configurable temporal transformer with attention pooling, plus a BiLSTM baseline wired to the identical training and evaluation harness. Config lives in YAML; the architecture answers to it.

Input landmark sequence (B, T, 186)
Feature projection + LayerNorm (B, T, 256)
Sinusoidal positional encoding + pos(t)
Transformer encoder ×4 · 8 heads (B, T, 256)
Attention pooling over time (B, 256)
Dropout 0.15 → linear head (B, 50)
Softmax → confidence filter p, argmax

WHY ATTENTION OVER TIME. ISL signs are movements — an arc, a reversal, a hold. Self-attention lets frame 3 interrogate frame 41 directly, so the model learns motion grammar instead of memorizing static poses. The pooling head's weights double as an interpretable “which frames mattered” trace.

PRIMARY MODEL

ISLTransformer

  • Multi-head self-attention over the full window
  • Parallel training, strong on fast movements
  • Attention pooling = interpretable time weights

src/model.py — attention pooling (excerpt)

class AttentionPooling(nn.Module):
    def __init__(self, dim: int) -> None:
        super().__init__()
        self.score = nn.Linear(dim, 1)

    def forward(self, x, key_padding_mask=None):
        scores = self.score(x).squeeze(-1)            # (B, T)
        if key_padding_mask is not None:
            scores = scores.masked_fill(key_padding_mask, float("-inf"))
        weights = torch.softmax(scores, dim=-1).unsqueeze(-1)
        return (x * weights).sum(dim=1)               # (B, dim)

WLASL ≠ ISL. Do not mix them.
WLASL, MSASL and similar corpora are American Sign Language. Handshapes, movement paths and two-handed symmetry differ systematically from ISL. The pipeline tags every sample with its dataset version so a mixed-language model can never be trained — or deployed — by accident.

Missing hand? Zeros + presence flag 0 — the model learns “no hand here” instead of hallucinating one. Non-finite coordinates are sanitized and logged, never silently propagated.

07 / FIELD MANUAL

Run it, debug it, extend it — without surprises.

Troubleshooting from real failure modes, an honest line between what this system is and is not, and the upgrade path from isolated signs to sentence-level translation.

TROUBLESHOOTING

cv2.VideoCapture returns False / black frames
OS-level camera permission, or another app holds the device. On Linux check v4l2 (v4l2-ctl --list-devices); on macOS grant permission to Terminal/Streamlit. The app surfaces CAMERA_OFFLINE rather than crashing.
MediaPipe fails to install on Apple Silicon
Use the mediapipe-silicon wheel for arm64 macOS, Python 3.10–3.11. x86 wheels do not load on arm64 even under Rosetta for the native graph.
CUDA available but AMP crashes
Set training.amp: false in configs/config.yaml, or match your torch build to the driver (torch+cu118 vs cu121). The trainer auto-falls back to float32 with a logged warning.
INCLUDE download is blocked
Access is license-gated by design. Request it via include-dataset.github.io with institutional details; meanwhile bootstrap with your own recordings via scripts/prepare_dataset.py.
Accuracy drops on new signers
Expected without signer-diverse data. Validate with signer-aware splits, increase augmentation, and enrol new signers into the capture script — then retrain through the gated pipeline.
Webhook returns 403 / times out
Make.com rotates webhook URLs after inactivity. Feedback is always persisted locally first (logs/feedback.jsonl), so a dead webhook never loses a correction — replay it with scripts/replay_feedback.py.

WHAT THIS SYSTEM IS — AND ISN'T

SHIPPED
Isolated sign classification — one sign, one prediction. What this repo trains and measures.
NEXT
Continuous sign recognition — unsegmented stream → gloss sequence (CTC / attention decoding).
LATER
Sentence-level translation — gloss → grammatical text with a language model. ISL grammar ≠ English word order.

PRIVACY & ETHICS — NON-NEGOTIABLE

  • Recorded sessions require explicit consent; consent metadata travels with the data.
  • Frames are processed locally. Only prediction metadata (word, confidence, timestamp) ever leaves the device — and only to a webhook the user configures.
  • Sign language is a full language. Gloss output is not a grammatical translation; never market it as one.
  • Deaf signers review approved samples before any retraining. No silent dataset growth.
  • A model is promoted to production only through the four recorded gates — never automatically.
